Asbestos Permit Check

Run this before any work that drills, cuts, lifts, sands, or otherwise disturbs a wall, ceiling, floor, or pipe. If you're not sure, the answer is stop — not guess.
Based on the Control of Asbestos Regulations 2012 (CAR 2012) and HSE guidance.
This is a first-line screening check, not a survey. Any doubt about presence, extent, or condition of ACMs — stop and get specialist advice before proceeding.
Trust asbestos duty holder contact should be on file at each site's H&S noticeboard / management plan.
